# FIN202 Interactive Manga — Cat Capital

A self-contained Vietnamese comic-style learning site for FIN202.

## Open the site
Once GitHub Pages finishes publishing, visit:

https://mainhatanhee-a11y.github.io/mynovel/fin202-interactive-manga/

## Features
- 12 chapters, 36 illustrated comic pages
- Dialogue bubbles appear above each manga panel
- 174 plain-language concept explanations
- Formula panels, common exam traps and question-pattern radar
- 12 checkpoint quizzes with explanations
- Searchable glossary, bookmarks and local reading progress
- Responsive desktop/mobile layout

## Run locally
Open `index.html` in a modern browser. The page is self-contained; MathJax and Google Fonts are loaded from CDNs when available. No package installation or build step is required.

Quiz answers, bookmarks and reading progress stay in the browser's local storage.
